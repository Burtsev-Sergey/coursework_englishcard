# Итоговая работа EnglishCard

## Бот Learning English - Telegram-бот «Обучение английскому языку»


### Описание проекта
Бот Learning English — Telegram-бот для изучения английского языка. Бот взаимодействует с базой данных, где хранится словарный запас пользователя.
Пользователь изучает английские слова: выбирает правильный вариант ответа из 4 вариантов.
Пользователь добавляет или удаляет слова из базы данных. Для каждого пользователя реализуется личный словарь.


### Цель проекта
Цель проекта - помочь пользователю увеличить словарный запас английских слов.
Проект реализован с помощью Telegram-бота и базы данных для хранения английских слов и перевода на русский язык в личном словаре пользователя.


### Функционал бота
1. Приветственное сообщение:


После запуска бот отправляет пользователю приветственное сообщение, которое объясняет функции бота.


2. Изучение слов:


Бот предлагает пользователю выбрать перевод слова на русском языке из 4 случайных английских слов.
Пользователь отвечает - нажимает на кнопки с английскими словами.
При правильном ответе бот подтверждает выбор правильного ответа.
При неправильном ответе предлагает попробовать снова.
Пользователь переходит к следующей выборке слов - нажимает кнопку "Дальше".


3. База данных:


Предварительно заполненная таблица базы данных default_words содержит набор из 10 английских слов и русского перевода. Слова таблицы default_words доступны каждому пользователю.
Бот показывает пользователю выборки из таблицы default_words пока пользователь не добавит 5 новых слов в личный словарь. 
Новые слова для изучения бот добавляет в таблицу базы данных user_words.
Бот показывает пользователю выборки слов из таблицы user_words, когда число слов в личном словаре будет минимум 5.
Слова, которые добавил пользователь, образуют личный словарь в таблице базы данных user_words.
Пользователи добавляют и удаляют слова только в личном словаре.


4. Добавление новых слов:


Пользователь пополняет личный словарь - отправляет боту английское слово и через пробел его перевод. 
Бот проверяет наличие нового слова в личном словаре пользователя.
Если слова нет - добавляет в словарь.
Если слово присутствует - просит ввести другое слово.


5. Удаление слов:


Пользователь удаляет ненужные слова из личного словаря - отправляет боту английское слово для удаления.
Бот проверяет наличие слова в личном словаре пользователя.
Если слово присутствует - удаляет из словаря.
Если слова нет - просит ввести другое слово.


### Технологии
Язык программирования: Python
База данных: PostgreSQL
Telegram API: взаимодействие бота с мессенджером.


### Команды бота


/start или /cards — запуск бота.
/ADD_WORD — добавить новое слово в словарь.
/DELETE_WORD — удалить слово из словаря.
/NEXT — перейти к следующей выборке слов.


### Пример взаимодействия пользователя с ботом:


#### После команды /start или /cards бот отправляет приветственное сообщение:


"Привет 👋


Бот помогает практиковаться в английском языке.
Тренировки можно проходить в удобном для себя темпе.
У вас есть возможность использовать тренажёр как конструктор и собирать свою собственную базу для обучения.


Для этого воспользуйтесь инструментами:
- Добавить слово ➕,
- Удалить слово 🔙.


Перейти к следующему слову:
- Дальше⏭.


Ну что, начнём ⬇️"


#### Бот задаёт вопрос:
Выберите перевод слова: "Слово на русском языке"
Пользователь выбирает кнопку с ответом.


При верном выборе сообщение бота:
"Отлично!❤
Английское слово -> Перевод"
При неверном выборе сообщение бота:


"Допущена ошибка!
Попробуйте ещё раз вспомнить слово 'Перевод'"


Для перехода к новой выборке слов нажмите кнопку "Дальше⏭"


#### Кнопка "Добавить слово➕" добавляет слово. Сообщение бота после нажатия на кнопку:
"Введите новое английское слово и его перевод через пробел"


Сообщение бота после ввода слова:
"Карточка с новым словом "Слово" и переводом "Перевод" успешно создана!


Возвращаемся к изучению английских слов📖"
Бот задает вопрос с выбором нового слова.


#### Кнопка "Удалить слово🔙" удаляет слово. Сообщение бота после нажатия на кнопку:
"Введите английское слово для удаления из вашего словаря."


Сообщение бота после удаления слова:
Слово "Английское слово" и перевод удалены из личного словаря.
Возвращаемся к изучению английских слов📖


Бот задает вопрос с выбором нового слова.


#### Кнопка "Дальше⏭". Переход к новой выборке из 4-х слов.


Принудительной остановки бота пользователем нет.
